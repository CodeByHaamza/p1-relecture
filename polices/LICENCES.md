# Les polices embarquées

Trois familles, toutes sous **SIL Open Font License 1.1**, qui autorise
explicitement de les héberger et de les redistribuer avec un projet :

| police | usage ici | auteur |
|---|---|---|
| **Marcellus SC** | les titres, les noms de personnages | Brian J. Bonislawsky (Astigmatic) |
| **Spectral** | le corps du dialogue — dessiné pour la lecture à l'écran | Production Type |
| **IBM Plex Mono** | les codes du jeu, les jauges, les étiquettes | IBM / Bold Monday |

Seuls les sous-ensembles `latin` et `latin-ext` sont embarqués : le corpus est
français. Les fichiers viennent de Google Fonts, rapatriés par
[`outils/polices.py`](../outils/polices.py).

## Ce que la licence demande

- garder cet avis ;
- ne pas vendre les polices seules ;
- si on les modifiait, ne plus les appeler par leur nom d'origine.

Rien de tout cela n'est en cause ici : les fichiers sont servis tels quels.
